# Unofficial Little Dog Rescue design previews

Three design-only concepts for the existing Squarespace 7.1 site, retaining Shelterluv. Not affiliated with or approved by Little Dog Rescue. Public-source photos are attributed in assets/provenance.json. No production website changes.

Open index.html through a static web server. The dog directory loads the existing external Shelterluv integration; official applications and payment destinations are real services. The preview has no submission backend.

No license to the rescue’s photographs or branding is granted by publishing this review.
